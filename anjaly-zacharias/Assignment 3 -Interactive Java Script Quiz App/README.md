MULTIPLE CHOICE QUIZ APPLICATION (JavaScript)

OBJECTIVE:
To develop a multiple-choice quiz application using JavaScript, DOM manipulation, and event handling. The application dynamically displays questions, processes user input, and shows the final score.

DESCRIPTION:
This project is a web-based quiz application where questions are stored in a JavaScript array and displayed dynamically on a webpage. Each question has four options. The user selects an answer, receives instant feedback, and proceeds to the next question. At the end, the total score and a feedback message are displayed along with a restart option.

TECHNOLOGIES USED:
HTML – Structure of the webpage  
CSS – Styling and layout  
JavaScript – Logic, DOM manipulation, and event handling  

FEATURES:
- Displays 8 multiple-choice questions  
- Dynamically generates question and option buttons  
- Highlights correct answers in green and wrong answers in red  
- Shows correct answer if user selects wrong option  
- Tracks score for each correct answer  
- Displays final score with feedback message  
- Restart button to retake the quiz  

VARIABLES USED:
questions – Array storing quiz data  
currentQuestionIndex – Tracks current question  
score – Stores user score  

FUNCTIONS USED:
startQuiz() – Initializes the quiz  
showQuestion() – Displays question and options  
selectAnswer() – Handles answer selection  
resetState() – Clears previous content  
showScore() – Displays final result  
restartQuiz() – Restarts the quiz

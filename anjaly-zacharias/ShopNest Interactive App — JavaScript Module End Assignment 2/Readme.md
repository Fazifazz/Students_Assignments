# 🛍️ ShopNest Interactive E-Commerce Application

## 📌 Project Overview

ShopNest is a fully interactive single-page e-commerce web application built using JavaScript. The application demonstrates core frontend development concepts such as DOM manipulation, asynchronous data fetching, array methods, and localStorage by simulating a real-world online shopping experience.

---

## 🎯 Features

### 🛒 Product Management

* Products are dynamically loaded using **Fetch API (async/await)** from a JSON file
* No hardcoded HTML — all products rendered using JavaScript DOM manipulation
* Each product displays image, name, price, rating, and discount

### 🔍 Search & Filter

* **Live search** filters products instantly as the user types
* **Category filters** (Electronics, Clothing, Footwear, Books)
* Search and filter work **together simultaneously**

### 🛍️ Cart Functionality

* Add products to cart
* Increase (+) / Decrease (–) quantity
* Remove items from cart
* Automatic total price calculation

### 💾 Local Storage

* Cart data is saved using **localStorage**
* Cart is restored automatically on page refresh

### 🔔 UI Enhancements

* Live cart count in header
* "No products found" message when no matches
* Premium UI with responsive product grid and side cart panel

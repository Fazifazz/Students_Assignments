# 🎬 Movie Watchlist

A responsive Movie Watchlist web application built using React and Vite.

The application allows users to browse movies, filter them by genre, and create a personal watchlist by adding and removing movies.

## 🚀 Features

- 🎥 Display movies with:
  - Movie title
  - Genre
  - Release year
  - Rating
  - Movie poster
- 🔍 Filter movies by genre:
  - All
  - Action
  - Comedy
  - Drama
- ❤️ Add movies to a personal watchlist
- 🚫 Prevent duplicate movies from being added
- ✅ Show `Added` state for movies already in the watchlist
- 🗑️ Remove movies from the watchlist
- ⏳ Loading spinner while movie data is being fetched
- ❌ Display a message when no movies match the selected genre
- 📱 Responsive design for desktop, tablet, and mobile devices
- 🎨 Styled using Bootstrap and custom CSS
- 🌐 Movie data loaded from a local JSON file using Axios

## 🛠️ Technologies Used

- Axios

- CSS

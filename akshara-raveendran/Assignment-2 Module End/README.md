# 🛍️ ShopNest - Interactive E-Commerce Website

ShopNest is a responsive and interactive e-commerce website built using HTML, CSS, Bootstrap, and JavaScript.

The project demonstrates JavaScript concepts such as DOM manipulation, array methods, Fetch API, async/await, event handling, and localStorage.

## 🚀 Features

- Dynamic product rendering
- 12 products loaded from a JSON file
- Fetch API with async/await
- Live product search
- Category filtering
- Combined search and category filtering
- Add products to cart
- Increase and decrease product quantity
- Remove products from cart
- Dynamic cart item count
- Dynamic cart total
- Cart persistence using localStorage
- "No products found" message
- Newsletter form validation
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- JSON
- Fetch API
- localStorage
- Bootstrap Icons

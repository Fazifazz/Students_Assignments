# 🍳 Recipe Finder

A recipe app built with React that helps users search for recipes, view ingredients and cooking instructions, and save their favourite meals.

## Features

- Search recipes by name
- View recipe details and images
- See ingredients and cooking instructions
- Add and remove favourite recipes
- Responsive design

## Tech Stack

- React
- Vite
- React Router DOM
- Axios
- React Context API
- CSS
- TheMealDB API

## API

Recipe data provided by [TheMealDB](https://www.themealdb.com/api.php).

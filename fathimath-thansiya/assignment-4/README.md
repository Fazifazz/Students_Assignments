# JavaScript Quiz App

A simple **JavaScript Quiz App** built using HTML, CSS, and JavaScript.

## Features

- 8 JavaScript questions
- 4 options for each question
- Dynamically creates questions and buttons using DOM methods
- Shows the selected answer as correct or wrong
- Displays the correct answer when a wrong option is selected
- Tracks the user's score
- Next Question button
- Final score screen with feedback
- Restart Quiz button

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Listeners
- Arrays and Objects
- Functions

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Select an answer and play the quiz.

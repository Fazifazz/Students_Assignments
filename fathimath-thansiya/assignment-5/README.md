# ShopNest 🛍️

ShopNest is a simple e-commerce website built using HTML, CSS, Bootstrap, and JavaScript.

## Features

- View products
- Search products
- Filter products by category
- Add products to cart
- Increase/decrease quantity
- Remove products from cart
- Calculate cart total
- Save cart using Local Storage
- Responsive design

## Technologies

- HTML
- CSS
- Bootstrap
- JavaScript
- JSON
- Local Storage

## How to Run

1. Download or clone the project.
2. Open it in VS Code.
3. Run `index.html` using **Live Server**.

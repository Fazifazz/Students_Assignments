🎤 Voice Calculator

A simple calculator that uses voice commands to perform basic mathematical operations.

Features
🎤 Voice input using Web Speech API
➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
Displays the recognized speech
Displays the calculation result
Handles invalid commands
Prevents division by zero
Responsive and beginner-friendly UI
Technologies Used
HTML
CSS
JavaScript
Web Speech API
Example Commands

You can say:

10 plus 5

Result:

15

Other examples:

20 minus 8
6 times 4
100 divided by 5
How to Run
Download or clone the project.
Open index.html in a supported browser.
Click Start Speaking.
Allow microphone access.
Speak a calculation.

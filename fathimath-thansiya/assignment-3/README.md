# Price and Discount Calculator

A simple JavaScript project that calculates the discounted price, tax amount, final price, shipping status, and stock availability of a product.

## Technologies Used

- HTML5
- JavaScript

## Features

- Discount calculation
- Tax calculation
- Final price calculation
- Free shipping check
- Stock status check
- Console output summary

## Project Structure

```text
assignment-2/
│
├── index.html
├── script.js
└── README.md
```

## How to Run

1. Open `index.html` in a browser.
2. Open Developer Tools (`F12`).
3. Go to the **Console** tab to view the output.

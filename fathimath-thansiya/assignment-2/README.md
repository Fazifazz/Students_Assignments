# ShopNest — Assignment 2

A responsive e-commerce website created as **Assignment 2** using **HTML, CSS, and Bootstrap 5**.

## 📌 About the Project

**ShopNest** is a modern and responsive online shopping website designed to showcase products for men, women, footwear, and accessories.

The project focuses on creating a clean user interface using HTML, CSS, and Bootstrap components and utilities.

## ✨ Features

- Responsive navigation bar
- ShopNest brand logo and navigation links
- Search bar
- Shopping cart icon
- Hero section with call-to-action buttons
- Product/category sections
- Product cards with images and discounts
- Wishlist icons
- Responsive layout for different screen sizes
- Bootstrap components and utility classes
- Responsive footer

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Bootstrap 5.3**
- **Bootstrap Icons**
- **Unsplash** for product images

1. Clone or download this repository.

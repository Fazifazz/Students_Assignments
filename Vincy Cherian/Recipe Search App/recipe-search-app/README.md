RecipeHub – Recipe Search App
====================================

RecipeHub is a React application for discovering recipes, viewing recipe details, and managing favourite recipes. It uses the DummyJSON Recipes API to retrieve recipe data.

Technologies Used
- React
- Vite
- JavaScript
- React Router DOM
- Axios
- Bootstrap / Bootstrap Icons (if included in the project)
- DummyJSON Recipes API
API Endpoints
- All recipes: https://dummyjson.com/recipes
- Search recipes: https://dummyjson.com/recipes/search?q=pizza
- Recipe details: https://dummyjson.com/recipes/1
The Axios instance uses https://dummyjson.com as its base URL.

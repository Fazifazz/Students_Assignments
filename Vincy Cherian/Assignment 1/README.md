# Aarohan Restaurant Website

A modern and responsive restaurant website built for **Aarohan – Good Food, Great Moods**.  
This project is designed as a restaurant landing page showcasing the restaurant story, menu highlights, opening hours, and contact information.


## Features

- Responsive design for mobile, tablet, and desktop
- Hero section with restaurant branding
- About section with restaurant story
- Starters, Main Course, and Dessert menu highlights
- Opening hours section
- Contact and location section
- Clean and modern UI

---

- HTML5
- CSS3

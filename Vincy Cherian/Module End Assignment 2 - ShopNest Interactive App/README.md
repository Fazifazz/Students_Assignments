# 🛍️ ShopNest – Interactive E-Commerce Web App

ShopNest is a responsive single-page e-commerce web application developed using **HTML, CSS, JavaScript, Bootstrap, and Fetch API**.

This project was created as part of the **JavaScript Module End Assignment 2** to demonstrate practical skills in DOM manipulation, event handling, arrays, asynchronous JavaScript, Fetch API, localStorage, and dynamic UI updates.

---

## 📌 Project Overview

ShopNest provides an interactive shopping experience where users can:

- Browse products loaded dynamically from a public API
- Search for products
- Filter products by category
- View product details in a Bootstrap modal
- Add products to the shopping cart
- Increase or decrease product quantities
- Remove products from the cart
- View the running cart total
- See the live cart item count
- Preserve cart data using localStorage
- Use the application on different screen sizes

# Quiz App

## 📌 Project Overview

This project is an interactive multiple-choice quiz application developed using **HTML, CSS, and JavaScript**.

The application contains 8 JavaScript-related questions. Users can select an answer, receive immediate feedback, move to the next question, and view their final score at the end of the quiz.

The project was created as part of the JavaScript Fundamentals assignment to practice **arrays, objects, loops, DOM manipulation, event handling, and conditional logic**.

---

## ✨ Features

- Contains 8 multiple-choice questions
- Dynamically displays questions and options using JavaScript
- Allows users to select one answer for each question
- Highlights the selected answer based on whether it is correct or incorrect
- Displays the correct answer when the selected answer is wrong
- Tracks the user's score
- Displays the final score after completing the quiz
- Provides feedback based on the score
- Includes a **Restart Quiz** option
- Uses DOM manipulation to dynamically create quiz elements

# EquipTrack — Industrial Equipment Rental & Fleet Management System

Built as part of the **Agentic MERN** curriculum (Sessions 27 through 45).

## 🚀 Quick Start (One-Click)
Double-click `run-project.bat` in this folder. It will launch both the backend server and frontend Vite development server and open your browser automatically.

### Manual Start:
#### 1. Backend:
```bash
cd backend
node server.js
# Runs on http://localhost:5000
```

#### 2. Frontend:
```bash
cd frontend
npm run dev
# Open http://localhost:5173
```

## 🛠️ Concepts Implemented (From Syllabus PDFs)
- **Session 27:** React with Vite, JSX, Components, Props destructuring, `.map()` list rendering with keys.
- **Session 28:** `useState`, lifting state up, controlled inputs.
- **Session 29:** Conditional rendering (`&&`, ternary), event handling, list filtering.
- **Session 30:** `useEffect` with dependency array, cleanup function (`cancelled = true`), simulated AI processing delays.
- **Session 31:** Axios instance (`src/api/axiosInstance.js`), full CRUD integration with status code handling.
- **Session 32:** Reusable multi-field forms with validation, regex checks, and `touched` states.
- **Session 33:** React Router v6 (`BrowserRouter`, `Routes`, `Route`, `Link`, `NavLink`, dynamic `useParams`, `useSearchParams`, `404 Not Found`).
- **Session 34:** Custom Hooks (`useFetch`, `useDebounce`, `useForm`, `useLocalStorage`).
- **Session 35:** Advanced React (`useReducer` for rental cart, `React.memo` on `EquipmentCard`, `useMemo` for filtering, `useCallback`).
- **Session 36:** "Vibe Coding" AI assistant widget with smart project equipment advice.
- **Sessions 43 & 44:** Node.js file system async operations (`fs.promises`), `path.join()`, `.env` environment variables, `async/await`.
- **Session 45:** Express application, `express.json()`, `express.Router()` for `/api/equipment` and `/api/rentals`, HTTP status codes (`200`, `201`, `400`, `404`).
